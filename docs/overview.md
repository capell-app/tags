# Tags

<!-- prettier-ignore-start -->

## What it does for you

Tags let you group content with labels and keep those labels tidy. You create tags, apply them to content, and merge duplicates so similar tags don't pile up.

## Your screens

- **Tags**: your list of tags and how many things use each.

## What you can do

- Create tags.
- Apply tags to content.
- Merge duplicate tags into one.

## Where to find it

Go to **Tags** in the admin to manage your tags.

## Good to know

- Group content with **tags** so it is easy to find and filter.
- Merge duplicate tags to keep things tidy (for example "news" and "News").
- The list shows how many items use each tag, so you can spot ones to merge or remove.
