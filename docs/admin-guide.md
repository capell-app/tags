# Using Tags

This guide is for editors and owners who keep tags tidy. Every step uses the labels you see on screen.

## What you're looking at

| Screen or signal | What it tells you |
| --- | --- |
| **Tags** list | Every tag and how many items use it |
| **Total Taggables** | How much content carries tags |
| Two similar tags | A likely duplicate to merge |

## What to do when...

| Situation | What to do |
| --- | --- |
| You see duplicate tags | Use **Merge tags** and pick the **Target tag** to keep |
| A tag is barely used | Consider removing it or merging it into a broader tag |
| Content is hard to find | Apply a consistent set of tags |
| Tags are inconsistent (case, spelling) | Merge the variants into one canonical tag |

## Settings and retention

- Merging is permanent: the items move to the **Target tag** and the duplicates go away.
- Agree a small set of tags and reuse them, rather than inventing new ones each time.
